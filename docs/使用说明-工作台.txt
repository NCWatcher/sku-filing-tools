SKU 建档工作台 v3.0 · 使用说明
════════════════════════════════════════

【打开】
　桌面双击  SKU建档工作台.lnk
　（第一次会弹「无法验证发布者」，点「运行」；再弹 UAC 点「是」）


【三个页签，从左到右就是一天的流程】

　① 编码库　—— 把聚水潭的编码粘进来
　　　在聚水潭「按款式」框选行，Ctrl+C，
　　　点到这个页签的大框里，Ctrl+V。
　　　粘完自动识别，下面会显示「识别到 N 个款、M 个编码、品类…」。
　　　确认数字对，点「写入编码库」，直接写进
　　　　SKU建档工具\款式编码文档-模板.xlsx
　　　写入规则：新的追加、已有的跳过、品类空着的补齐、
　　　　　　　　同一货号+花色+尺码出现两个编码 → 报冲突，不覆盖。

　② 生成　—— 写这次的 SKU 组合
　　　格式：货号-花色+花色 / N条装 / 尺码1,尺码2
　　　例：2621-奶酪白+冰清粉 / 1件装 / M,L,XL,2XL
　　　　　MX088+MX089 / 保暖两件套 / 110,120,130,140,150,160
　　　　　79005+79002 / 4条装 / M,L,XL
　　　设好「组合商品名称 / 标签 / B列逗号 / 组间空行」，点「生成预览」。

　　　★ 花色名里带破折号（比如 粉色-EO、黄色-EO）照原样写：
　　　　　　39120-粉色-EO+黄色-EO+蓝色-EO / 3条装 / L,XL
　　　　　破折号不会把后面的颜色吞掉。

　　　★ EO 提到前面也认（和上面完全等价）：
　　　　　　39120-EO-粉色+黄色+蓝色 / 3条装 / L,XL
　　　　　后面几个颜色只写颜色名即可，工具会自动补 -EO。

　　　★ ALLIN = 该款式当前所有颜色：
　　　　　　39120-EO-ALLIN / 6条装 / 5XL
　　　　　展开成 粉色-EO、紫色-EO、绿色-EO、蓝色-EO、虾色-EO、黄色-EO 六条。
　　　　　写 EO-ALLIN 只取带 EO 的颜色；只写 ALLIN 取全部颜色。
　　　　　（以后这个款加了新颜色，ALLIN 自动包含，不用改组合）

　　　★ 带 EO 和不带 EO 是两个不同 SKU，不会混：
　　　　　　39120-粉色　　只找「粉色」，找不到就报红，不会拿「粉色-EO」顶上。

　③ 预览 / 导出　—— 先看，再改，最后导出
　　　表格里能看到每一行的 组合编码 / 标签 / 名称 / 商品编码 / 数量 / Q。
　　　红底 = 这个码在编码库里查不到；黄底 = Q 列公式会算错需手动核查。
　　　双击任意格可以改（标签、名称、商品编码、Q）；也可以选中行删掉。
　　　确认无误后点「导出 Excel」，按规范 17 列、红标题、组间空行写出来。


【文件存哪儿】
　「输出到」选文件夹，「文件名」自己起（留空=自动命名）。
　指定的文件夹写不进去时，会自动改存到工具自带的「输出」文件夹，并在下方写明原因。


【列的含义（导出的表）】
　A 组合商品编码　B 组合装商品标签　C 与 A 相同　D 组合商品名称
　J 商品编码　K 数量=1　L 应占售价（按 Q 分摊）　Q 条数
　Q 列：内裤型用公式 =LEFT(TEXTAFTER(J,"T"),1)*K；身高型/背心型写 1。


【出问题】
　「编码文档正被 WPS/Excel 打开着」→ 先保存并关闭那个 xlsx，再点写入。
　「查不到某某花色」→ 回①把那个款的颜色粘进来，或者在③里直接双击补编码。
